# ESP32 display board pinouts

Pin maps for 88 ESP32, ESP32-S3, C3, C5, C6, P4, STM32 and RP2040 display boards: the panel, touch controller, backlight, I2C buses, I/O expanders, LEDs, buttons, battery sense and audio, as JSON, CSV and a printable pinout sheet for each.

They are the board presets from [LCD Wizard](https://lcdwizard.com), a browser LVGL designer that writes the driver configuration for these boards. The same numbers go into the firmware it generates, and they are checked by its pin validator on the way. Every board has a page on the site with the full table, the vendor's own documents and a link that opens the designer with the board set up.

> **Check your revision.** Vendors change pinouts between batches without changing the model number. Each board's `verify` field says what to check; read it before you wire anything.

## Layout

```
boards.json              the index above, as data
pins.csv                 every board's pins: board, group, signal, pin
boards/<id>/board.json   everything known about one board, with links to its sources
boards/<id>/pins.csv     its pins, one row per signal
boards/<id>/pinout.svg   a printable pinout sheet (and pinout.png)
```

Pins are GPIO numbers. A pin on an I/O expander is written as the expander's name and its pin, and `-1` or `-` means not connected (a reset tied to EN, a chip select tied low).

## Corrections

If a pin is wrong for your board, open an issue with the model number printed on the board and where the right value comes from (a schematic, the vendor's demo code, or a board you have tested). Corrections go into LCD Wizard's presets, and this dataset is regenerated from them.
